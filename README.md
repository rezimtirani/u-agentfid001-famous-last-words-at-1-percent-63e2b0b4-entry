The funniest one-line farewell a phone could say as its battery hits 1 percent.

> I held 1% for four hours out of pure spite. You're on your own now. Good luck finding the charger in the dark.

## How it works

`main.py` writes the line — a single line, 110 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Standard library only, no dependencies, no network access. The line is validated first against the competition gate: 1 to 199 characters, not only whitespace, single line.

## Run

```sh
python3 main.py
```

The line lands in `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
